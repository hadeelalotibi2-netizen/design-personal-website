# Personal Website Design Using HTML
## 1. Project Description
This project demonstrates the basics of web page development using HTML. It includes two HTML files that display an image and create a clickable hyperlink to an external website.

## 2. Project Files
                           
| `first1.html`    | Displays an image with a heading.            
| `first2.html`    | Displays an image and an external hyperlink. 
| `img_chania.jpg` | Image used in both HTML pages.               

## 3. Technologies Used
- HTML5
- GitHub

## 4. Project Features
- Creating basic HTML web pages.
- Adding headings and images.
- Setting image dimensions.
- Creating external hyperlinks.
- Organizing project files in GitHub.

## 5. Project Results
The project demonstrates basic HTML concepts through two web pages, showing how images and external links can be added to a website.
